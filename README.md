# Pokémon Freekie - Edición Tahuantinsuyo

Fangame de Pokémon hecho en **Python puro con Pygame** (no RPG Maker).
Ambientado en la región del Tahuantinsuyo con 103 Pokémon originales.

## Cómo jugar

1. Instala Python 3.10+
2. Instala dependencias: pip install pygame numpy
3. Ejecuta: python main.py

## Controles

- Flechas: mover / navegar menús
- X / Enter: interactuar / confirmar
- F: menú pausa
- I: mochila
- S: guardar partida
- M: silenciar música
